Features

Built for Local Minecraft Server Hosting

Everything you need to run, configure, and share Minecraft servers locally on Windows without touching the command line.

Terminal & Diagnostics
  • ANSI color console with live logs and command history.
  • Offline crash summaries powered by local Ollama models.
  • Real-time CPU, RAM, and tick stability telemetry.
  • One-click graceful stop and process termination.
  • Filter logs by keywords, warnings, and errors.
Lifecycle & Safety
  • Safe shutdown with world saves before closing.
  • Auto-restart after crashes with backoff limits.
  • Port collision checks before server launch.
  • Low disk space warnings below 2 GB.
  • Keeps Windows awake while servers run.
  • Alerts when memory usage crosses 80%.
Java & Runtimes
  • Adoptium runtimes for Java 8, 11, 17, 21, and 25.
  • Picks the right Java version based on your server.
  • Kept inside PocketMC without touching system PATH.
  • Separate working folders for each server.
  • Runs without requiring administrator rights.
  • Includes PHP 8.2 for PocketMine-MP.
Networking & Remote
  • Playit.gg tunnels for sharing without port forwarding.
  • Optional Cloudflare Quick Tunnels support.
  • Mobile web dashboard via local network PIN or QR code.
  • Operator and viewer roles for dashboard users.
  • Discord Rich Presence with live player counts.
  • Built-in UDP tunnel mapping for Simple Voice Chat.
Content & Add-ons
  • Search and download mods and plugins from Modrinth.
  • CurseForge mod browser and Poggit plugin support.
  • One-click shortcuts to world, config, and plugin folders.
  • Toggle individual mods and plugins on or off anytime.
  • Drag-and-drop installer for .mcpack and .mcaddon files.
  • One-click Geyser and Floodgate setup for Bedrock cross-play.
Backups & Storage
  • Scheduled backups synced directly to Google Drive.
  • Optional sync to OneDrive and Dropbox.
  • Zip archive integrity verification with SHA-256.
  • Automatic backup schedules with cron support.
  • Flushes and disables world saves during backup creation.
  • All server files remain stored directly on your PC.

Distributed, multi-user web panel for Minecraft and Steam serversPocketMC is local-first, running natively without requiring Node.js runtimes, database setup, daemon installation, or reverse-proxy configuration. Python web panel supporting multi-server scheduling and backupsPocketMC runs local-first in user-space with zero prerequisites. Crafty Controller is panel-first (requiring browser setup) and its documentation warns of a 90% risk of world chunk corruption/shredding when running under Docker Desktop/WSL on Windows. PocketMC also includes built-in playit.gg/Cloudflare tunnel auto-provisioning and direct cloud backups (Google Drive, OneDrive, Dropbox).

PocketMC provisions exact Adoptium Java/PHP runtimes automatically, avoids Docker cgroup OOM hard-kills with graceful RCON shutdown hooks, and includes built-in Playit.gg/Cloudflare tunnels and direct cloud sync (Google Drive, OneDrive, Dropbox).
