Engineering

Production Stability

Built with native desktop resilience to protect your worlds, your hardware, and your player community around the clock.

Crash Loop Protection

Monitors server instance processes with automated backoff logic and a 3-loop crash limit to protect your CPU from runaway execution cycles.

RCON Save-Flush Safeguard

Executes a clean save-off and save-all sequence before creating backups, guaranteeing zero chunk write corruption or lost player inventory.

Windows Sleep Inhibitor

Seamlessly hooks into Windows power management to prevent your computer from sleeping while servers are active, resuming normal sleep upon shutdown.

80% System RAM Safety Guard

Validates requested server memory allocations against real-time system memory headroom to prevent Windows out-of-memory lockups and freezing.

SHA-256 Cloud Checksums

Validates archive hashes during OAuth uploads to Google Drive, Dropbox, and OneDrive to ensure backups can always be restored with complete fidelity.

Isolated Desktop User-Space

Operates cleanly inside your local user directory. Manages self-contained runtimes without modifying global system PATH environment variables.
