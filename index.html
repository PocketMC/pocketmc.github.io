Features

What it does

Engineered to eliminate terminal complexity, safeguard data sovereignty, and automate local Minecraft server operations.

Server Engines
  • Vanilla (Official Mojang JARs)
  • Paper (High-performance Spigot)
  • Fabric (Lightweight & modular)
  • Forge (Classic mod loader)
  • NeoForge (Modern mod loader)
  • Bedrock Dedicated Server (BDS)
  • PocketMine-MP (PHP 8.2 PM5)
Lifecycle & Safety
  • RCON graceful save-holding flush
  • Crash recovery with auto-backoff
  • Port-collision preflight guard
  • Low-disk warning (< 2 GB guard)
  • Windows sleep mode inhibition
  • 80% System RAM over-allocation alert
Java & Runtimes
  • Adoptium JREs (Java 8, 11, 17, 21, 25)
  • Auto-selection based on server JAR
  • Managed app-local dependencies
  • Isolated instance directories
  • Runs in local user directory
  • Auto PHP PM5 for Bedrock
Networking & Remote
  • Integrated Playit.gg tunnel agent
  • Cloudflare Quick Tunnels support
  • Responsive mobile web dashboard
  • Instant QR code mobile pairing
  • Multi-user roles & permission scopes
  • Discord Rich Presence with live server status
Content & Add-ons
  • In-app Modrinth marketplace browser
  • CurseForge browser & Poggit integration
  • Three-dot menu Explorer folder jumps
  • One-click mod & plugin enable/disable toggle
  • Bedrock .mcpack, .mcaddon ingestion
  • Automatic Geyser & Floodgate cross-play
Backups & Storage
  • Automated Google Drive replication
  • Dropbox & OneDrive OAuth sync
  • SHA-256 archive integrity checks
  • Automated Cron & reboot scheduling
  • Pre-backup RCON save sync
  • 100% data sovereignty on your disk

How PocketMC Compares

From lightweight desktop launchers to distributed Linux web panels, see how PocketMC stacks up against alternative hosting tools.

ToolCategoryCore StrengthWhere PocketMC Wins
PocketMC
Native Windows Desktop AppComplete local Minecraft server management with zero setup overheadBest overall fit for local self-hosting: Java (with NeoForge), native BDS, PocketMine-MP, Geyser/Floodgate crossplay, managed Adoptium/PHP runtimes, RCON-secured backups with automatic Google Drive/OneDrive/Dropbox cloud replication, auto-configured Playit.gg & Cloudflare tunnels, AI log summaries, and active open-source trust.
SquidServers
Desktop AppUser-friendly local hosting with official BDS, Geyser crossplay, Modrinth mod/plugin installer, Playit.gg tunnels, and metricsPocketMC is 100% free and open-source (MIT), provides native PocketMine-MP (PHP) runtime orchestration alongside Java and BDS, features RCON-synchronized backups with automated cloud replication (Google Drive, OneDrive, Dropbox), and includes built-in AI log summaries and Discord integrations.
auto-mcs
Desktop GUI (Python Tkinter)Python Tkinter GUI with playit.gg, Modrinth search, and custom scripting (amscript)PocketMC offers a modern native Windows interface instead of a legacy Tkinter interface, provides native Bedrock Dedicated Server (BDS) and PocketMine-MP (PHP) instances out-of-the-box, and features scheduled RCON-held backups with built-in Google Drive, OneDrive, and Dropbox replication.
MCSManager
Web panel (Node.js)Distributed, multi-user web panel for Minecraft and Steam serversPocketMC is local-first, running natively without requiring Node.js runtimes, database setup, daemon installation, or reverse-proxy configuration. It manages all Java/PHP runtimes automatically and provides a guided tunnel wizard, avoiding the high setup complexity of a distributed panel/daemon architecture.
Crafty Controller
Web panel (Python Tornado)Python web panel supporting multi-server scheduling and backupsPocketMC runs local-first in user-space with zero prerequisites. Crafty Controller is panel-first (requiring browser setup) and its documentation warns of a 90% risk of world chunk corruption/shredding when running under Docker Desktop/WSL on Windows. PocketMC also includes built-in playit.gg/Cloudflare tunnel auto-provisioning and direct cloud backups (Google Drive, OneDrive, Dropbox).
Pterodactyl Panel
Web panel & Wings daemon (Linux VPS)Enterprise client-server web app (PHP/Laravel + Redis + Nginx) and Go daemon (Wings) over Docker for 24/7 Linux VPS and commercial hostingPocketMC is built for zero-sysadmin local desktop self-hosting without requiring a Linux VPS, Docker engine, MariaDB database, Nginx reverse proxy, or router port forwarding. PocketMC provisions exact Adoptium Java/PHP runtimes automatically, avoids Docker cgroup OOM hard-kills with graceful RCON shutdown hooks, and includes built-in Playit.gg/Cloudflare tunnels and direct cloud sync (Google Drive, OneDrive, Dropbox).
Essential Mod
Client mod / P2P hostingEasy friend world hostingPocketMC manages real server instances. Essential is convenient for casual worlds, but it is not a serious server management app.
Minehut
Managed cloud hostFree-to-start hosted servers and community hostingPocketMC wins on local ownership, file control, fewer platform restrictions, and self-hosted privacy/control.
playit.gg
Tunnel serviceExcellent public tunnel servicePocketMC includes Playit.gg as part of a full server-management workflow instead of forcing users to combine tools manually like it's 2012.
