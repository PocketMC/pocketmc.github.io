Connectivity

Discord Integration

Connect your desktop client with Discord to display live server status, connected player counts, tunnel connection addresses, and active server software directly on your Discord profile.

Discord Rich Presence (RPC)

PocketMC communicates directly with your local Discord desktop client via the native Discord IPC pipe using official application registration (1507742265240715354).

  • Real-Time Game Activity: Displays your active server state (Starting, Online, or Stopping) and elapsed uptime.
  • Player Counts: Shows live connected player metrics (e.g. 4/20 Players) synchronized with the server process.
  • Engine Branding: Dynamically loads high-resolution badges matching your server engine (Paper, Fabric, NeoForge, Forge, BDS, PocketMine-MP, or Vanilla).
  • Public Join Address: When Playit tunneling is enabled, your public join address is displayed so friends can copy it directly from your Discord profile.
  • Geyser Crossplay Detection: If Geyser is installed on your server, PocketMC automatically detects both endpoints and formats both Java and Bedrock addresses in your presence status.
  • Website Link Button: Includes an interactive button linking friends directly to the official PocketMC website.

Customizable Display Preferences

You have complete control over what information is broadcast to Discord. In SettingsDiscord RPC, you can toggle individual presence elements:

SettingDescription
Enable Discord RPCMaster toggle for initializing the Discord IPC client.
Show Server NameDisplays your custom instance name rather than a generic "Minecraft Server" label.
Show Engine & VersionShows the server loader and Minecraft version (e.g. Paper • 1.21.4).
Show Player CountDisplays real-time online players vs max player capacity.
Show Server AddressShares your active Playit tunnel join address publicly on your Discord profile.
Show Software IconRenders the specific server loader logo as the large presence asset.
Show Download ButtonAdds an interactive "Download PocketMC" button linking to the project website.
Show Idle StatusDisplays "Managing Servers • Idle" when PocketMC is open with no servers currently running.
