Developer & Security

Authentication & Security

PocketMC implements a robust security model designed to safeguard user credentials, isolate instance sandboxes, prevent brute-force attacks, and protect local system resources.

DPAPI Credential Encryption

Sensitive secrets—including third-party cloud OAuth tokens (Google Drive, Dropbox, OneDrive) and Remote Control user password hashes—are never stored in plaintext on disk.

On Windows, PocketMC encrypts all secrets using the native Windows Data Protection API (DPAPI) (ProtectedData.Protect) with DataProtectionScope.CurrentUser. Encryption keys are managed directly by the Windows kernel and cryptographically bound to your specific Windows User Account Security Identifier (SID). If another user or process copies your settings.json file to another machine or account, the secrets cannot be decrypted.

Cookie-Based Session Auth

The embedded Remote Control server uses ASP.NET Core cookie authentication (RemoteCookies).

  • Password Hashing: User passwords are salted and hashed using cryptographic PBKDF2/SHA-256 before storage.
  • Security Stamps: Every user profile includes an internal security stamp. If a user password is changed or an account is modified, the security stamp rotates, immediately invalidating all active remote sessions.
  • 24-Hour Expiration: Session cookies carry a strict 24-hour expiration policy and are flagged with HttpOnly and SameSite=Lax to prevent cross-site scripting (XSS) extraction.

Multi-User Permission Scopes

When inviting friends or co-admins to help manage your servers via the web dashboard, you can define individual user accounts with specific granular permissions:

Permission FlagCapabilities Granted
AllowRemoteConsoleCommandsAllows sending terminal commands and streaming live console output via WebSockets.
AllowRemotePlayerActionsAllows executing Kick, Ban, Pardon, Op, and De-op player actions.
AllowRemoteServerSettingsAllows viewing and modifying server.properties.
AllowRemoteServerAddonsAllows viewing installed plugins/mods and toggling them enabled or disabled.
AllowRemoteFileManagerAllows browsing directories, editing configs (< 1 MB), and uploading files.
AllowRemoteServerBackupsAllows viewing backup history and triggering manual world backups.
AllowedInstanceIdsRestricts the user's visibility and controls strictly to designated server instances.

Brute-Force Rate Limiting

The Remote Control daemon enforces proactive rate limiting (RemoteRequestLimiter) using an in-memory token bucket algorithm:

  • Login Protection: Authentication attempts to /api/login are capped at 5 attempts per minute per client IP. Excess attempts receive an immediate 429 Too Many Requests response.
  • Console Command Flooding: Command submissions to running server instances are limited to 30 requests per minute to prevent accidental or malicious terminal flooding.

Windows UWP Loopback Isolation

By default, Windows AppContainer security blocks Minecraft Bedrock Edition (which runs as a Universal Windows Platform app) from connecting to loopback network addresses (127.0.0.1 or localhost) on the same machine.
