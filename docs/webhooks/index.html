Webhooks & Events

Subscribe to real-time lifecycle and operational events from your Minecraft servers to trigger custom Discord bots, notifications, and monitoring automations.

Supported Events

PocketMC broadcasts webhook notifications when key state changes occur:

Event NameTrigger Condition
instance.startedServer process has spawned and completed listening socket binding.
instance.stoppedServer process has exited gracefully following RCON save-flush.
instance.crashedProcess terminated unexpectedly with a non-zero exit code or uncaught error.
backup.completedWorld backup archive created, checksummed, and uploaded to cloud.
player.joinedA player authenticated and joined the Minecraft game world.
player.leftA player disconnected from the server instance.

HMAC Signature Verification

To verify that the webhook request genuinely originated from your local PocketMC daemon, inspect the X-PocketMC-Signature header. The header contains an HMAC-SHA256 signature calculated using your configured webhook secret key.
