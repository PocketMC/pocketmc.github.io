Operations & Safety

Cloud Backups

Protect your Minecraft worlds from accidental corruption, hardware failures, and griefing with automated, checksummed cloud replication.

Zero-Corruption RCON Save-Sync

Backing up an active Minecraft world without pausing disk writes often leads to corrupted chunk boundaries and region file discrepancies.

PocketMC uses native RCON automation before creating backup archives:

  1. Issues save-off to suspend world writes to disk.
  2. Issues save-all flush to force all memory chunks onto persistent storage.
  3. Skips ephemeral lock files (such as session.lock) that cause archive extraction errors.
  4. Packages the world and database into an optimized compressed zip archive.
  5. Issues save-on to resume standard in-game autosaving.

Supported Cloud Providers

PocketMC supports native OAuth 2.0 replication to three leading cloud storage platforms:

  • Google Drive: Dedicated application folder synchronization with automatic quota alerts.
  • Dropbox: Direct chunked upload stream with version retention.
  • Microsoft OneDrive: Graph API integration for personal and business accounts.

Automated Cron Backups

Configure backups to trigger automatically at set intervals. In Instance SettingsBackups, you can set standard hourly schedules, daily maintenance windows, or custom 5-field Cron expressions.
