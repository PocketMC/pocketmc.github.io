Developer & Security

Remote Control API

When Remote Control is active, PocketMC runs an embedded ASP.NET Core Kestrel web server on port 25580. It serves the responsive web dashboard and exposes a REST and WebSocket API for controlling your Minecraft servers.

Base Endpoint: http://127.0.0.1:25580 · Authentication: Cookie session via POST /api/login

Authentication & Sessions

To interact with protected API endpoints, authenticate by sending your credentials to /api/login. Upon successful authentication, the daemon issues a secure RemoteCookies session cookie.

Note: The login endpoint enforces rate limiting (maximum 5 failed attempts per minute per IP address).

Instance Lifecycle Control

Start, stop, or restart any instance by its UUID:

MethodEndpointDescription
GET/api/instancesLists all instances accessible to the authenticated user.
GET/api/instances/{id}/statusFetches live run state, player count, CPU %, and memory usage.
POST/api/instances/{id}/startSpawns the server process and binds listening sockets.
POST/api/instances/{id}/stopSends graceful stop command with RCON save-flush before process exit.
POST/api/instances/{id}/restartStops the running instance cleanly, then initiates a fresh boot.

Live Console & WebSockets

PocketMC supports both buffered polling and bidirectional real-time WebSocket terminal streaming:

  • Buffered Output: GET /api/instances/{id}/console/history returns recent console output lines stored in the circular memory buffer.
  • Command Input: POST /api/instances/{id}/console/command accepts a JSON body {"command": "say Hello"}. Rate limited to 30 requests per minute.
  • WebSocket Stream: Connect to /ws/instances/{id}/console to stream live terminal log lines directly to your browser as they are written by the server process, and transmit commands through the persistent socket.

Player Moderation & Settings

Manage connected players and server properties remotely:

  • Player List: GET /api/instances/{id}/players returns online player usernames and player count.
  • Player Actions: POST /api/instances/{id}/players/{name}/[kick|ban|pardon|op|deop] executes moderation commands directly through the server console or sidecar ban list.
  • Server Properties: GET /api/instances/{id}/properties and PUT /api/instances/{id}/properties allow remote inspection and editing of MOTD, gamemode, difficulty, max-players, PvP, whitelist, and view distance.

File Manager & Backups

PocketMC includes sandboxed file management and remote backup triggers:

  • Browse Files: GET /api/instances/{id}/files?path=plugins lists directory contents with file sizes and timestamps.
  • Read/Write Configs: GET /api/instances/{id}/files/content?path=config.yml and PUT /api/instances/{id}/files/content view and edit text files under 1 MB directly from the web browser.
  • Upload & Delete: POST /api/instances/{id}/files/upload uploads files via multipart form data; DELETE /api/instances/{id}/files?path=... removes files safely inside the instance folder sandbox.
  • Backups: GET /api/instances/{id}/backups lists available backup archives with SHA-256 integrity status; POST /api/instances/{id}/backups triggers an immediate background RCON save-flush backup.
