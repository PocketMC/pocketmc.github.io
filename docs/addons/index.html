Plugins & Mods

PocketMC features an integrated addon browser for Modrinth and CurseForge, automatic dependency resolution, safe file installation, and zero-deletion enable/disable toggles.

In-App Marketplace Browsing

Instead of manually hunting for mod files across external websites and worrying about compatibility errors, PocketMC queries the official Modrinth and CurseForge APIs directly inside the desktop client.

  • Context-Aware Filtering: The marketplace automatically filters search results to match the exact loader (Paper, Fabric, Forge, NeoForge, Quilt) and Minecraft version of your selected instance.
  • Direct One-Click Installation: Click Install to download the validated JAR file directly into your server's mods/ or plugins/ folder.
  • PocketMine-MP Support: For Bedrock PocketMine-MP instances, PocketMC connects directly to the Poggit plugin repository.

Automated Dependency Resolution

Many modern Minecraft mods require prerequisite library mods (such as Fabric API, Cloth Config, or Architectury) to function. PocketMC includes an automated dependency resolver (DependencyResolverService):

  1. When you select a mod to install, PocketMC inspects its metadata manifest for declared required dependencies.
  2. It checks your instance's active addon inventory to determine if any dependencies are already installed.
  3. If missing dependencies are detected, PocketMC prompts you and automatically downloads compatible versions in the background before staging the primary mod.

Addon Inventory & State Management

PocketMC maintains a structured inventory of all installed plugins and mods with safe file management:

FeatureImplementation
Enable / Disable ToggleTemporarily disables an addon by appending .disabled to the filename. The mod or plugin is ignored on server startup without losing config files or player data.
Update ChecksQueries Modrinth and CurseForge hashes to compare installed versions against the latest release for your Minecraft version.
Explorer JumpClick the three-dot context menu on any addon card and select Show in Explorer to jump directly to the target file on disk.
Safe UninstallSafely removes the addon JAR and its corresponding configuration directory upon explicit user confirmation.

Geyser & Floodgate Crossplay

PocketMC provides built-in automated provisioning for Geyser and Floodgate, allowing Minecraft Bedrock Edition players (on Windows, Android, iOS, Xbox, PlayStation, and Nintendo Switch) to join Java Edition servers:

  • During server creation or addon configuration on Paper or Fabric, check Enable Bedrock Crossplay.
  • PocketMC automatically downloads the latest stable builds from the official GeyserMC API (download.geysermc.org).
  • PocketMC automatically configures listening ports (25565 TCP for Java and 19132 UDP for Bedrock).
  • When Playit tunneling is enabled, PocketMC registers both Java and Bedrock tunnel endpoints and displays both join addresses on your dashboard and Discord Rich Presence.
