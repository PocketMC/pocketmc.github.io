Java & Runtimes

PocketMC eliminates system-wide Java conflicts by downloading, isolating, and managing Eclipse Adoptium JRE binaries directly inside your application data directory.

Version Compatibility Matrix

Minecraft versions have strict Java bytecode requirements. PocketMC automatically inspects your server jar and selects the verified matching Adoptium runtime:

Minecraft VersionRequired JavaEngine Types
Minecraft 1.20.5 – LatestJava 21 / Java 25Vanilla, Paper, Fabric, NeoForge
Minecraft 1.18 – 1.20.4Java 17Vanilla, Paper, Fabric, Forge
Minecraft 1.17 – 1.17.1Java 16Vanilla, Paper, Fabric
Minecraft 1.12 – 1.16.5Java 11 / Java 8Vanilla, Paper, Forge
Minecraft 1.8.8 – 1.11.2Java 8Vanilla, Paper, Classic Forge

Disk Storage Optimization

To conserve disk space on initial installation, PocketMC pre-fetches the latest Long-Term Support (LTS) runtime (Java 25/21). Older runtimes (Java 17, 11, 8) are pulled on-demand only when creating an older server instance.

Memory Guards & Allocation Limits

When configuring minimum and maximum heap memory (-Xms and -Xmx), PocketMC evaluates your total physical RAM. If your requested server allocation exceeds 80% of available system memory, an allocation guard triggers to prevent Windows memory exhaustion and desktop lockups.

Custom Java Path Override

If you prefer to use a custom GraalVM, OpenJ9, or pre-installed JDK binary, you can navigate to SettingsRuntimes and provide a custom path to any java.exe binary.

PocketMine-MP (PHP 8.2 PM5)

PocketMine-MP is written in PHP rather than Java. PocketMC automatically downloads, stages, and manages an app-local, high-performance PHP 8.2 runtime configured specifically for PM5. It operates in isolation without requiring PHP to be installed system-wide or added to your Windows environment variables.
