Server Engines

PocketMC supports 7 server engines across Minecraft Java Edition and Bedrock Edition with automated version indexing, SHA checksum verification, and one-click jar and binary provisioning.

Vanilla (Official Mojang)

Vanilla is the first and default server type selected in the PocketMC creation wizard. It delivers a pure, unmodded Minecraft experience using official server JARs downloaded directly from Mojang's distribution network.

PocketMC queries Mojang's official version manifest (launchermeta.mojang.com/mc/game/version_manifest_v2.json) to index every official release and snapshot build from Minecraft 1.8.8 through the latest version. When a version is selected, PocketMC fetches the version metadata JSON, resolves the official Mojang server download URL, and validates the file against Mojang's SHA-1 checksum before launch.

  • Default selection for new server creation.
  • Direct downloads from Mojang's official CDN with SHA-1 integrity validation.
  • Full support for release versions and snapshot builds.
  • Auto-negotiated Eclipse Adoptium Java runtimes (Java 8, 11, 17, 21, or 25).

Paper (High Performance)

Paper is the industry standard for high-performance Spigot-compatible servers, engineered to provide substantial performance improvements and tick rate stability.

PocketMC queries PaperMC's official API (api.papermc.io / fill.papermc.io) to dynamically retrieve builds from Minecraft 1.8.8 through the latest release. PocketMC resolves the latest build (or a specified build number) and verifies the download against PaperMC's SHA-256 checksum.

  • Full Spigot and Bukkit plugin compatibility.
  • Asynchronous chunk loading and optimized entity ticking.
  • Automated Geyser & Floodgate cross-play installer integration.
  • Direct in-app plugin installation and update checks.

Fabric

Fabric is a lightweight, modular modding toolchain with fast boot times and a minimal memory footprint.

PocketMC queries Fabric's official meta service (meta.fabricmc.net) to combine the target Minecraft game version (1.14+), the latest stable Fabric Loader, and the official Fabric Installer into a runnable server JAR (v2/versions/loader/{game_version}/{loader_version}/{installer_version}/server/jar).

  • Fast launch times and minimal overhead.
  • Direct integration with the in-app Modrinth marketplace browser.
  • Automated dependency resolution for required libraries (Fabric API, Cloth Config, etc.).
  • Automatic Java version negotiation based on the target game version.

Forge

Forge is the classic modding framework powering thousands of extensive community modpacks for Minecraft 1.8.8 and above.

PocketMC queries Forge promotional metadata to resolve recommended or latest builds. It downloads official installer JARs directly from Forge Maven (maven.minecraftforge.net) and automatically runs the headless installer within the instance directory to stage required libraries and server dependencies.

  • Broadest compatibility with classic Minecraft modpacks.
  • Automated headless installer execution during instance creation.
  • Preflight Java runtime verification to match mod loader requirements.

NeoForge

NeoForge is the modern, community-driven fork of Forge designed for modern Minecraft releases (1.20.2+).

PocketMC queries NeoForge metadata (maven.neoforged.net) to discover available builds for each supported Minecraft release. It downloads the verified installer JAR from NeoForge Maven and executes installation in a sandboxed directory.

  • Optimized modding platform for modern Minecraft versions (1.20.2 and newer).
  • Automated headless installation and dependency verification.
  • In-app Modrinth and CurseForge marketplace filtering for NeoForge mods.

Bedrock Dedicated Server (BDS)

Official Windows Bedrock Dedicated Server binaries from Mojang enable native cross-platform gameplay for Bedrock Edition players on Windows, Android, iOS, Xbox, PlayStation, and Nintendo Switch.

PocketMC queries versioned release and preview manifests to download official Windows BDS ZIP packages directly from Mojang CDN. The binaries are extracted into an isolated instance workspace without touching system directories.

  • Official Mojang Bedrock binaries for stable releases and preview builds.
  • Automatic Windows loopback network isolation exemption (CheckNetIsolation.exe) so Bedrock clients on the host machine can connect to local instances.
  • Persistent pocketmc-bans.json sidecar providing persistent player ban moderation across BDS server restarts.
  • Zero Java dependency — runs natively on 64-bit Windows.

PocketMine-MP (PHP)

PocketMine-MP is an ultra-fast, extensible Bedrock server engine written in PHP.

PocketMC queries GitHub releases from pmmp/PocketMine-MP to download the executable PocketMine-MP.phar package. It automatically provisions an app-local, pre-compiled PHP 8.2 PM5 runtime from pmmp/PHP-Binaries into the instance runtime folder, completely eliminating the need to install PHP system-wide or adjust Windows environment variables.

  • App-local managed PHP 8.2 runtime configured for PM5.
  • Direct integration with the Poggit plugin repository.
  • Ultra-fast startup times and low CPU/memory utilization.
