Server Engines

PocketMC supports all major Minecraft Java Edition loaders and Bedrock Edition server software with automated version indexing and one-click jar provisioning.

Paper

Paper is the industry standard for high-performance Spigot-compatible servers. PocketMC queries PaperMC's official v2 REST API to fetch builds for Minecraft 1.8.8 through the latest release.

  • Full Spigot and Bukkit plugin compatibility.
  • Asynchronous chunk loading and optimized entity ticking.
  • Automated Geyser & Floodgate cross-play installer integration.

Fabric

Fabric is a lightweight, modular modding framework. PocketMC queries Fabric's official meta service to combine the latest Fabric Loader and Minecraft Game Version into a runnable server jar.

  • Fast boot times and minimal memory footprint.
  • Integrated Modrinth in-app mod marketplace browser.
  • Automatic Java version negotiation (Java 17, 21, or 25).

NeoForge & Forge

For large community modpacks, PocketMC provides native installer-based bootstrapping for both modern NeoForge (1.20.2+) and classic Forge (1.8.8+).

When creating a Forge or NeoForge instance, PocketMC automatically executes the server installer in a headless sandbox, verifies jar dependencies, and prepares launch arguments.

Bedrock Dedicated Server (BDS)

Official Windows BDS binaries from Mojang are downloaded and managed directly. PocketMC handles manifest parsing, loopback isolation workarounds (via CheckNetIsolation.exe), and automatic version staging.

PocketMine-MP

PocketMine-MP is an ultra-fast, extensible PHP-based Bedrock engine. PocketMC provisions an app-local PHP 8.2 PM5 binary runtime and integrates Poggit plugin repository browsing directly within your client.
