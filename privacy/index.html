Privacy & Security Policy

PocketMC operates under a strict local-first architecture. Your server files, worlds, credentials, and configurations live exclusively on your personal hardware, never on remote commercial servers.

Storage & Local Encryption

All Minecraft world saves, player inventories, configuration files, terminal logs, and server databases are stored locally on the disk folder you designate. No cloud synchronization or off-site transmission occurs unless you explicitly authenticate and authorize a third-party cloud provider.

On Windows, third-party credentials—including OAuth tokens for Google Drive, Dropbox, and OneDrive, as well as remote dashboard administrative passwords—are encrypted via the Windows Data Protection API (DPAPI). These secrets are tied cryptographically to your Windows user account security identifier (SID) and cannot be read by other user accounts on the machine.

Network Traffic & Tunneling

When you enable the integrated Playit.gg agent, server game packets are encrypted and routed through Playit.gg's global edge infrastructure to allow friends to connect without port forwarding. PocketMC does not inspect, store, or log player network traffic.

AI Diagnostics & Log Sanitization

PocketMC's optional AI Log Summary feature translates complex server logs and crash traces into plain-English reports.

  • Local Inference with Ollama: If you use local Ollama models, all processing takes place 100% on your machine with zero data leaving your hardware.
  • Cloud Providers: If you choose Google Gemini, OpenAI, Anthropic Claude, or Mistral, PocketMC pre-processes and scrubs the log before transmission—automatically stripping player IP addresses, email addresses, and sensitive tokens.

Telemetry & Crash Reports

PocketMC does not sell, license, or monetize user data. Any optional, anonymous diagnostic signals (such as application startup confirmation or error exceptions) are strictly non-identifiable and can be toggled off at any time in Settings.
