Privacy Policy

PocketMC operates under a strict local-first architecture. Your Minecraft server instances, worlds, credentials, and logs live on your own hardware. This policy describes all verified data flows, local encryption mechanisms, third-party integrations, and optional telemetry.

1. Local Storage & Credential Protection

All Minecraft server files, game worlds, player save data, whitelist/ban files, properties, and runtime logs are stored exclusively on your local disk (in your chosen server root directory or %LOCALAPPDATA%\PocketMC).

Sensitive credentials—including OAuth refresh tokens for cloud backup providers (Google Drive, Dropbox, OneDrive) and Remote Control user password hashes—are never stored in plaintext. On Windows, they are encrypted using the native Windows Data Protection API (DPAPI) (ProtectedData.Protect) scoped to the current user SID. A copy of the configuration files transferred to another account or computer cannot be decrypted.

2. Telemetry & Diagnostics (Opt-in)

PocketMC includes an optional telemetry service (TelemetryService) designed solely to measure application adoption, active server counts, and crash stability.

  • Master Control: Telemetry is controllable via the EnableTelemetry setting in settings.json and can be toggled on or off at any time in Settings.
  • Identifiers: PocketMC generates a random GUID (TelemetryClientId) stored in your local settings, along with a salted SHA-256 hash of your Windows Machine GUID (DeviceIdentifier.GetMachineId) to deduplicate install events without storing hardware serials or personal identities.
  • Installation & Upgrade Events: Sent once upon first launch or version update. Contains the client ID, salted machine ID hash, application version, upgrade flag, and approximate country.
  • Periodic Heartbeat: Sent every 5 minutes while the application is active. Contains the client ID, salted machine ID hash, app version, running state, active server count, and engine types (e.g. Vanilla, Paper, Fabric).
  • Server Action Counters: Reports high-level operational counts (such as server creation or start events) without instance names, paths, or file contents.
  • Approximate Country Lookup: To understand regional distribution, PocketMC makes a single request to ip-api.com or ipapi.co. Only the returned country name string is cached and reported. IP addresses are not stored in PocketMC telemetry databases.
  • Destination Infrastructure: Telemetry payloads are transmitted over encrypted HTTPS to PocketMC backend services hosted on Render (pocket-mc-proxy.onrender.com).

3. Application Logs & AI Analysis

Server terminal logs and crash stack traces remain 100% on your local disk. They are never automatically uploaded to any remote server.

If you explicitly choose to run an AI Log Summary or Crash Post-Mortem Analysis:

  • Local Inference (Ollama): When using a local Ollama model (http://localhost:11434), all analysis runs on your local CPU/GPU. Zero log data leaves your machine.
  • Cloud Providers: When using cloud providers (Google Gemini, OpenAI, Anthropic Claude, Mistral, or Groq), PocketMC's LogSanitizer automatically scrubs player IP addresses, player email addresses, local Windows user profile paths (e.g. C:\Users\username\...), and private tokens before sending the excerpt to the provider using your configured API key.

4. Third-Party Services & Connectivity

PocketMC integrates with external services to provide optional networking, downloads, and backups:

  • Playit.gg: When game tunneling is enabled, PocketMC launches the official Playit.gg agent. Gameplay network packets flow through Playit.gg's edge routing infrastructure to allow players to join without port forwarding.
  • Cloudflare Quick Tunnels: When Remote Control internet tunneling is active, PocketMC runs cloudflared to generate a temporary HTTPS ingress address. Traffic is encrypted in transit between your browser and local host daemon.
  • Download Providers: Server JARs, vanilla assets, and Adoptium JREs are retrieved directly from official distribution CDNs (Adoptium, Mojang, PaperMC, Fabric, Forge, NeoForge, and PocketMine).
  • Marketplaces (Modrinth & CurseForge): Search queries and addon package downloads communicate directly with the Modrinth and CurseForge public APIs.
  • Cloud Backup Providers (Google Drive, Dropbox, OneDrive): Backup archives are uploaded directly to your authenticated cloud storage account. OAuth token exchange for Google Drive is brokered through pocket-mc-proxy to protect application client credentials; Dropbox and OneDrive use direct PKCE.
  • Discord Rich Presence: Communicates exclusively with the local Discord desktop application via the local IPC pipe to display status on your profile. No Discord server communication occurs from PocketMC.

5. Data Deletion & Retention

Because PocketMC is a local desktop application, you retain complete authority over your data:

  • Deleting an instance folder or backup archive permanently removes the files from your storage.
  • Uninstalling PocketMC and removing %LOCALAPPDATA%\PocketMC completely erases all local settings, cached runtimes, credentials, and logs.
  • You can toggle telemetry off at any time in Settings, which permanently disables all background reporting loops.
